## Relationship to the other changelogs

[`CHANGELOG.md`](../../CHANGELOG.md) in the repository root is generated by
release-please from commit messages. It is complete and per-version, but it
is a list of commits: it tells you what changed, not what you can now do.
These notes are written by hand.

[`firmware/CHANGES`](../../firmware/CHANGES) is the firmware changelog, with
its own version numbers. Firmware and software release separately, so check
both.
